JANANISREE S. — PORTFOLIO WEBSITE
================================

Responsive static portfolio built with HTML, CSS and vanilla JavaScript.

OPEN LOCALLY
1. Extract this ZIP.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Keep assets/ and certificates/ beside index.html.

FEATURES
- Your uploaded portrait is used in the hero section.
- Responsive navigation, polished navy/violet/teal styling, mobile layout and theme toggle.
- Contact section includes recognizable GitHub, email, phone and LinkedIn SVG icons.
- Education, skills, mini project, activities, contact details, and certificate library.
- All certificate links are local relative paths so they work after extracting the ZIP.
